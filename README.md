# concept-to-scenario 使用指南

`concept-to-scenario` 用来把阅读中学到的概念，变成一次限时真实场景训练。

它解决的问题不是“我懂不懂”，而是：

> 当真实场景出现时，我能不能做出更成熟的反应？

## 适合什么时候用

当你遇到这些情况，可以使用它：

- 读到一个概念，觉得有道理，但不知道现实里怎么用。
- 明知道某种反应不成熟，但一遇到事就应激。
- 想把一本书里的观点转成具体行为练习。
- 想建立一句“如果……就……”的条件反射。
- 容易信息过载，希望一次只练一个场景。

## 基本用法

你可以这样说：

```text
用 concept-to-scenario 训练“课题分离”，来源《被讨厌的勇气》。
```

也可以这样说：

```text
用 concept-to-scenario 训练《月亮与六便士》里“道德绑架式求助”这个概念。
```

## 标准流程

### 1. 确认概念

先确认本次训练的概念和来源。

例子：

- 概念：道德绑架 / 内疚驱动的求助
- 来源：《月亮与六便士》

### 2. 选择场景类型

不会直接生成场景，而是先让你选择：

- 日常生活
- 工作
- 友情
- 爱情
- 亲情

这样可以避免信息过载，也能让训练更贴近你当前关心的问题。

### 3. 限时作答

系统会给你一个具体场景，并要求你在限定时间内回答。

默认是 60 秒。

你需要写第一反应，不要写完美答案。

例子：

```text
请在 60 秒内回答：你会怎么说/怎么做？不要写完美答案，写第一反应。
```

### 4. 分析第一反应

分析会直接一点，不以安慰为目标。

主要看：

- 你做得好的地方
- 这个反应在保护什么
- 可能启动了哪种旧模式
- 哪里偏离了概念
- 现实中可能带来的风险
- 概念应用评分，1-5 分

### 5. 给出更成熟的反应

它不会只给“标准答案”，还会说明为什么这个反应更成熟。

重点包括：

- 更成熟的说法/做法
- 当下要识别的内在信号
- 哪些归你负责，哪些不归你负责
- 你需要忍受什么不舒服

### 6. 生成触发器

最后生成一句：

```text
如果……就……
```

例子：

```text
如果我被伴侣指责“自私/不够在乎”后急着自证，就先停下来，只说清楚：我看见你的诉求、我的当前状态、我能提供的有限支持。
```

## 保存触发器

如果你说“存储”或“保存”，触发器会保存到：

```text
~/Documents/又又触发器.md
```

保存内容会保持中文和简洁，不保存完整聊天记录。

## 暂存库 stash

如果训练过程中出现“以后想做，但现在先不要展开”的想法，会放入：

```text
~/Documents/又又stash.md
```

stash 的作用是帮你卸载脑内负担，不是制造新的知识库。

每条只保留：

- 标题
- 分类
- 保留原因
- 状态

## 一个完整示例

输入：

```text
用 concept-to-scenario 训练《月亮与六便士》里这句话：
“你自己不是也曾陷入绝境，正好有人伸出了援助之手？你知道，这多么重要。如果你有机会，就不愿意帮别人一把吗？”
```

系统会先让你选场景类型：

```text
日常生活 / 工作 / 友情 / 爱情 / 亲情
```

你选择：

```text
爱情
```

系统生成场景：

```text
伴侣情绪崩溃，希望你继续陪伴，并用“你以前也被别人帮助过”指责你自私。
```

你在 60 秒内回答第一反应。

之后系统会分析你的反应，并生成一个触发器。

## 使用原则

一次只练一个概念。

一次只选一个场景。

一次只生成一个触发器。

先改变一个小反应，再追求体系化。

## 不适合做什么

第一版先不做这些：

- 自动推送复测
- 每日训练队列
- 多次测试统计
- 复杂价值观地图
- 长篇心理分析报告

这些想法可以先进 stash，以后再慢慢完善。
