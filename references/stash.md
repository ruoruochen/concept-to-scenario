# Stash 暂存规则

stash 用来降低信息过载。它是停车场，不是第二大脑。

## 条目格式

```markdown
## YYYY-MM-DD - 标题
- 分类：
- 保留原因：
- 状态：以后再说
```

## 分类

- 复测
- 队列
- 追踪
- 可视化
- 集成
- Skill 想法

## 规则

- 每条最多 4 行。
- 不写详细计划。
- 不保存长上下文或完整聊天记录。
- 重复想法合并，不新增一条。
- 30 天内仍用不上，就标为“也许以后”。

## 推荐文件

个人记录用 `~/Documents/又又stash.md`。

如果用户想放在当前项目里，用 `./又又stash.md`。
